# PF03 · TDD con Node.js e integración continua

Práctica de Proyecto Intermodular de 2.º DAW.

## Objetivo

Implementar las funciones fibonacci(n) y esPinValido(pin)
siguiendo el ciclo TDD: RED, GREEN y REFACTOR.

## Herramientas

- Node.js y npm.
- Vitest para pruebas unitarias.
- Git y GitHub para control de versiones.
- GitHub Actions para integración continua.

## Organización

Práctica individual con dos clones locales que representan
los entornos A y B, alternando los roles de testing y desarrollo.

## Ejecutar las pruebas

Instalar las dependencias con `npm ci`.

Ejecutar los tests con `npm test`.

Ejecutar los tests en modo continuo con `npm run test:watch`.
